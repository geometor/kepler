Modules
=======

The ``geometor.kepler`` Python package provides 100% exact symbolic ``SymPy`` and ``geometor.model`` constructions, 3D polyhedral and Voronoi sphere-packing analyzers, cyclotomic minimal-polynomial classifiers, uniform Archimedean tiling solvers, and celestial-harmony verifiers for Johannes Kepler's *Mysterium Cosmographicum* (1596/1621), *Strena seu de Nive Sexangula* (1611), and *Harmonices Mundi Libri V* (1619).

CLI Summary
-----------

.. code-block:: bash

   /home/phi/PROJECTS/geometor/.venv/bin/python -m geometor.kepler
